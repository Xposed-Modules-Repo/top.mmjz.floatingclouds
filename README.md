## 📌 项目简介

**FloatingClouds（浮云）** 是一个基于 **LSPosed** 框架的微信（`com.tencent.mm`）隐私增强 Xposed 模块（API 102），提供会话隐藏、联系人屏蔽、朋友圈净化、消息免打扰、VoIP 拦截等隐私增强功能。

核心技术栈 / Core Tech Stack：

- **libxposed API 102**（`io.github.libxposed:api:102.0.0`，Apache-2.0）：LSPosed 现代 Hook 注入框架
- **DexKit 静态扫描**（`org.luckypray:dexkit:2.2.0`，Apache-2.0）：通过 DkBridge / DexKitScanner 对微信 APK 进行 DEX 静态扫描，动态定位混淆类与方法
- **resolver 声明式规则解析**：混淆类解析引擎（DexKit / 规则系统），避免硬编码类名

## 🧩 功能列表

> 以下功能均可在插件设置面板（微信搜索栏输入打开设置指令，或微信「我-设置-关怀模式-长按开启」）中查看与配置，与插件 UI 一一对应。

### 基础设置

- **启用模块**：关闭后所有功能均不生效
- **配置名单**：管理密友名单（查看、移除、一键清空）

### 列表隐藏

- **不显示该聊天**：微信原生机制，独立于总开关
- **主页会话隐藏**：隐藏主页会话中的密友
- **通讯录隐藏**：隐藏通讯录列表中的密友
- **标签内隐藏**：隐藏标签成员及「谁可以看」选择器中的密友

### 搜索

- **隐藏主页搜索**：主页搜索不显示密友结果

### 访问拦截

- **禁止进入聊天**：禁止进入密友聊天界面
- **禁止查看资料**：禁止进入联系人资料页

### 社交隐藏

- **隐藏朋友圈入口**：隐藏密友资料页朋友圈入口及时间线中密友动态
- **隐藏发现页朋友圈入口**：隐藏发现页中的朋友圈入口
- **隐藏发现页入口**：隐藏视频号 / 看一看 / 小程序入口
- **隐藏最近转发**：最近转发列表不显示密友
- **隐藏我的朋友圈**：按需隐藏自己的朋友圈（长按详情加入隐藏、管理已隐藏列表）
- **隐藏朋友圈互动**：隐藏密友的点赞 / 评论
- **隐藏分组图标**：隐藏密友朋友圈的分组图标
- **隐藏状态页密友**：状态页不显示密友内容
- **隐藏存储空间聊天记录**：存储空间页面隐藏聊天记录整条目录
- **隐藏存储空间缓存**：存储空间页面不显示缓存条目

### 消息与通知

- **隐藏密友消息通知**：密友被隐藏后自动设置免打扰
- **阻止电话请求**：拒绝密友的电话联系
- **密友消息震动**：隐藏状态下收到密友消息时震动提示（可调强度，支持测试）
- **底栏字体加粗**：收到密友消息时底部导航栏文字加粗（可调强度；实验功能，澎湃 OS 上暂时不稳定）
- **圆点提示**：有密友未读消息时搜索框旁显示红点（可调大小；实验功能，澎湃 OS 上暂时不稳定）
- **拦截扫码登录**：拦截扫码登录确认弹窗
- **屏蔽微信热更新**：阻止 Tinker 热补丁

### 临时解除与恢复

- **多击标题解除**：多击微信标题临时解除隐藏（可调次数与间隔）
- **长按标题解除**：长按微信标题临时解除隐藏（可调触发时长）
- **离开对话隐藏**：进入密友对话后返回即恢复隐藏
- **离开微信隐藏**：按 HOME 离开微信后恢复隐藏

### 添加密友

- **会话列表长按添加**：主页会话列表长按弹出加入密友菜单
- **通讯录长按添加**：通讯录列表长按弹出加入密友菜单
- **菜单显示文字**：自定义长按添加菜单文字

### 提示自定义

- **操作提示**：操作提示总开关（默认关闭）
- **自定义提示文字**：临时解除 / 加入密友 / 取消密友 / 朋友圈隐藏 提示文字

### 指令与适配

- **自定义指令**：打开设置指令、临时解除指令（微信搜索框输入触发）
- **DexKit 适配**：一键扫描微信类名，查看解析缓存状态

### 开发者

- **数据库**：缓存微信数据库（开发者用）
- **版本详情**：热更新屏蔽状态、拦截记录、版本快照对比
- **清零拦截记录** / **模拟热更新**：热更新调试工具
- **清空所有配置**：清空全部开关、名单与缓存并重启微信
- **重启微信**
